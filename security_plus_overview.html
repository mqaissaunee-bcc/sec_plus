Domain 1: General Security Concepts
12%
Foundation of cybersecurity principles including security controls, fundamental concepts, change management, and cryptographic solutions. This domain establishes the groundwork for all cybersecurity professionals.
1.1 Compare and contrast various types of security controls
Understanding different categories and types of security controls that enforce the CIA triad.
Technical Controls Managerial Controls Operational Controls Physical Controls Preventive Controls Detective Controls
1.2 Summarize fundamental security concepts
Core principles including CIA triad, AAA framework, Zero Trust, and physical security measures.
CIA Triad Non-repudiation AAA Framework Zero Trust Physical Security Deception Technology
1.3 Explain the importance of change management processes
Business processes, technical implications, and documentation requirements for secure change management.
Approval Process Impact Analysis Backout Plan Version Control Documentation
1.4 Explain the importance of using appropriate cryptographic solutions
PKI, encryption methods, hashing, digital signatures, and cryptographic tools and technologies.
PKI Encryption Digital Signatures Hashing Certificates Key Management
Domain 2: Threats, Vulnerabilities, and Mitigations
22%
Comprehensive coverage of threat actors, attack vectors, vulnerability types, malicious activity indicators, and mitigation techniques. This domain focuses on identifying and responding to cybersecurity threats.
2.1 Compare and contrast common threat actors and motivations
Understanding different types of threat actors, their capabilities, and what drives their activities.
Nation-state Hacktivist Insider Threat Organized Crime Motivations Capabilities
2.2 Explain common threat vectors and attack surfaces
Various methods attackers use to compromise systems and networks, including social engineering tactics.
Email Threats Social Engineering Supply Chain Wireless Attacks Phishing Default Credentials
2.3 Explain various types of vulnerabilities
Different categories of vulnerabilities across applications, operating systems, hardware, and cloud environments.
Application Vulnerabilities OS-based Web-based Cloud-specific Zero-day Mobile Device
2.4 Given a scenario, analyze indicators of malicious activity
Recognizing signs of various attacks including malware, physical attacks, network attacks, and application attacks.
Malware Analysis Network Attacks Application Attacks Indicators Log Analysis Behavioral Analysis
2.5 Explain the purpose of mitigation techniques
Strategies and techniques used to reduce risk and protect enterprise environments from threats.
Segmentation Access Control Encryption Monitoring Hardening Least Privilege
Domain 3: Security Architecture
18%
Design principles for secure infrastructure, data protection strategies, and resilience planning. This domain covers how to architect secure systems from the ground up.
3.1 Compare and contrast security implications of different architecture models
Understanding various architectural approaches and their security implications.
Cloud Architecture Infrastructure as Code Microservices Virtualization IoT SCADA/ICS
3.2 Given a scenario, apply security principles to secure enterprise infrastructure
Practical application of security principles in real-world infrastructure scenarios.
Network Appliances Firewall Types VPN Port Security Device Placement Security Zones
3.3 Compare and contrast concepts and strategies to protect data
Data classification, states, and protection methods across different environments.
Data Classification Data States Data Sovereignty Protection Methods Geographic Restrictions Tokenization
3.4 Explain the importance of resilience and recovery in security architecture
Business continuity, disaster recovery, and high availability planning and implementation.
High Availability Disaster Recovery Backup Strategies Site Considerations Testing Power Management
Domain 4: Security Operations
28%
Day-to-day security operations including hardening, asset management, vulnerability management, monitoring, incident response, and investigation techniques. This is the largest domain covering practical security work.
4.1 Given a scenario, apply common security techniques to computing resources
Practical security implementation across various computing platforms and devices.
Secure Baselines Hardening Targets Mobile Solutions Wireless Security Application Security Sandboxing
4.2 Explain the security implications of proper hardware, software, and data asset management
Asset lifecycle management from acquisition to disposal with security considerations.
Acquisition Process Asset Tracking Inventory Management Disposal Sanitization Data Retention
4.3 Explain various activities associated with vulnerability management
Comprehensive vulnerability lifecycle from identification through remediation and validation.
Vulnerability Scanning Threat Feeds Penetration Testing CVSS Scoring Remediation Validation
4.4 Explain security alerting and monitoring concepts and tools
Monitoring systems, alert management, and security tools for continuous surveillance.
SIEM Log Aggregation Alerting SCAP DLP NetFlow
4.5 Given a scenario, modify enterprise capabilities to enhance security
Enhancing existing security infrastructure and implementing additional protective measures.
Firewall Configuration IDS/IPS Web Filtering Email Security EDR/XDR NAC
4.6 Given a scenario, implement and maintain identity and access management
Identity lifecycle management, authentication, authorization, and access control systems.
User Provisioning SSO MFA Access Controls Password Management PAM
4.7 Explain the importance of automation and orchestration
Security automation benefits, use cases, and considerations for implementation.
Use Cases Efficiency Benefits API Integration Scaling Complexity Supportability
4.8 Explain appropriate incident response activities
Incident response lifecycle, training, testing, and forensic activities.
IR Process Preparation Containment Eradication Recovery Lessons Learned
4.9 Given a scenario, use data sources to support an investigation
Digital forensics, data collection, and investigative techniques using various data sources.
Digital Forensics Log Data Chain of Custody Data Sources Packet Capture Metadata
Domain 5: Security Program Management and Oversight
20%
Governance, risk management, compliance, third-party management, and security awareness. This domain covers the management and oversight aspects of cybersecurity programs.
5.1 Summarize elements of effective security governance
Policies, procedures, standards, and governance structures for effective security management.
Policies Standards Procedures Governance Structures Roles & Responsibilities Monitoring
5.2 Explain elements of the risk management process
Risk identification, assessment, analysis, and management strategies throughout the enterprise.
Risk Identification Risk Assessment Risk Analysis Risk Register Risk Strategies BIA
5.3 Explain the processes associated with third-party risk assessment and management
Vendor assessment, selection, monitoring, and agreement management for third-party relationships.
Vendor Assessment Due Diligence SLA NDA Vendor Monitoring Supply Chain
5.4 Summarize elements of effective security compliance
Compliance monitoring, reporting, consequences, and privacy considerations across jurisdictions.
Compliance Reporting Monitoring Non-compliance Privacy Legal Implications Data Subject Rights
5.5 Explain types and purposes of audits and assessments
Internal and external audits, penetration testing, and various assessment methodologies.
Internal Audits External Audits Penetration Testing Reconnaissance Assessment Types Attestation
5.6 Given a scenario, implement security awareness practices
Security training programs, phishing campaigns, and user education initiatives.
Phishing Campaigns User Training Awareness Programs Reporting Social Engineering Remote Work
